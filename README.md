🛍️ E-Commerce Web Application (Node.js + Angular + PostgreSQL)
Welcome to the E-Commerce Web App — a full-stack, scalable solution built with Node.js (backend), Angular (frontend), and PostgreSQL (database) 🧩. This project is designed to handle real-world online shopping features with robust functionality and clean UI/UX.

✨ Key Features:

👥 Role-based login system for Customers and Sellers

🔐 Secure JWT authentication and OTP email verification

📦 Sellers can manage products, categories, subcategories, and inventory

🖼️ Support for file uploads (product images in binary format)

🛒 Customers can browse, add to cart, and place orders

🧾 Complete CRUD operations for product management

📡 Built with Express.js REST APIs and Prisma ORM

💻 Responsive design using Angular & Bootstrap

🚀 Perfect for learning modern web development, or using as a base for launching your own custom e-commerce platform!
